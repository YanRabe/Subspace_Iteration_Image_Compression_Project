# Subspace Iteration Applied to Image Compression -- ENSEEIHT 1SN Scientific Computing course
This project implements and compares various eigen-decomposition algorithms to extract dominant eigenvectors from matrices, primarily applied towards image compression. 

Starting from a basic Power Iteration method, this project progressively implements and tests Subspace Iteration algorithms, improving them step-by-step through Rayleigh-Ritz projections, block approaches, and deflation to decrease computation time and improve efficiency.

## Overview
The methods analyzed in this project are:
- **Power Method** (`power_v11.m`, `power_v12.m`): Algorithms to find the dominant eigenpair of a matrix.
- **Subspace Iteration v0** (`subspace_iter_v0.m`): Extension of the power method to a block of dominant eigenpairs.
- **Subspace Iteration v1** (`subspace_iter_v1.m`): Improved subspace iteration using the Rayleigh-Ritz projection.
- **Subspace Iteration v2** (`subspace_iter_v2.m`): Accelerated subspace iteration using mathematical block approaches ($A^p$).
- **Subspace Iteration v3** (if included in files): Accelerated and optimized implementation using a deflation method.

These algorithms are benchmarked against MATLAB's built-in `eig` function across multiple matrix distributions and ultimately applied to image compression using Singular Value Decomposition (SVD) through extracted eigenvectors.

## How to use
All the files are written in MATLAB and located in the `src/` directory.

### Quick Start
To test the implemented methods, you can open MATLAB, navigate to `src/` and run the different `test_` scripts provided.

For example, to run the comparison between the sub-space iterations v0 and v1:
```matlab
% In MATLAB command window
cd src/
test_v0v1
```

### Modifying parameters
You can easily adjust the parameters inside the top section of the test files (e.g., `test_v0v1.m:1`):

- **n**: Define the size o the generated symmetric square matrix.
- **imat**: Set the type of the matrix generated by matgen_csad.m. Choose between 1 to 4 for varying eigenvalue distributions.
- **eps**: Convergence tolerance setting.
